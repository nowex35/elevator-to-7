### ホラーの拡散エンジンは2系統
- **リアクション型**: 追跡+予測できない出現 → 叫ぶ実況 → 切り抜き(青鬼、Slender、FNAF、Lethal Company)
- **考察・ファンダム型**: じわじわ・異変・空白 → 考察/二次創作/ミーム(Backrooms、近畿地方、イシナガキクエ、Mouthwashing)
- 【解釈】両立に近い例が 8番出口(じわじわ系だが「気づいた/見逃した」瞬間が短尺クリップになる)。
- 【解釈】ユーザー希望の「青鬼」はリアクション型、「じわじわ不気味」は考察型寄り。ここの配分が論点。

## 2. やってはいけない/失速パターン

- **脅し型チェーン**: 【事実】チェーンLINE を中高生82%が受信、21%が転送。通信の秘密等で法規制できず、迷惑行為として問題視(高校生新聞)
- **偽メッセージ・匿名の送り主ヒント課金**: 【事実】NGL は偽メッセージ自動送信で FTC/LA地検と和解、返金原資450万ドル+18歳未満への提供禁止(FTC 2024-07)
- **明示的な拡散要求はプラットフォーム側で減点**: 【事実】TikTok は like-for-like 等を For You 対象外、Instagram はシェア/タグを明示的に求める投稿をおすすめしない方針(@creators 2024-06, 二次情報)、X は交換型エンゲージメント等を禁止しリーチ制限
- **一発ネタは消費されきる / 急成長は急失速**: 脳内メーカー、Clubhouse(約1か月)、BeReal(DAU 1,300万→約600万)、tbh・Gas(約1年で終了)
- **サーバー負荷・費用**: 【事実】내 트리를 꾸며줘 48時間でサーバー費500万ウォン+DDoS。Infinite Craft 作者「一番難しかったのはコスト管理とスケーリング」。Peing は負荷を理由に個人開発者が売却(J-CAST。見出し・要約での確認のみ、本文未確認)
- **クローン乱立**: Wordle

## 3. シェア導線の技術的事実

### 若者のSNS利用率(総務省 情報通信政策研究所 R7、2025-12調査)
| | LINE | YouTube | Instagram | TikTok | X |
|---|---|---|---|---|---|
| 10代 | 96.4% | 95.0% | 69.3% | 67.9% | 56.4%(前年62.1%) |
| 20代 | 97.7% | 96.3% | 82.6% | 61.5% | 73.4%(前年78.0%) |

- 【事実】若年女性の Instagram 投稿はストーリーズ38.1% vs フィード/リール7.4%(SHIBUYA109 lab. 2025)
- 【事実】高校生の Instagram は約9割が鍵垢(Studyplus 2024)
- 【事実】Wordle作者: シェア先は Twitter より WhatsApp/プライベートグループが多い(TechCrunch)
- 【解釈】若者の共有は「公開タイムライン」より「鍵垢ストーリーズ・LINEグループ」の閉じた輪で起きている比重が大きい可能性

### プラットフォーム別
- **X**: Web Intent(`x.com/intent/tweet`)は text/url/hashtags 等のみで**画像添付不可**。**画像を添付するとURLカードより画像が優先**(スクショ+リンクだとOGPカードは出ない)。`summary_large_image` は 2:1、5MB未満、7日キャッシュ
- **Instagram ストーリーズ**: 公式の Sharing to Stories はネイティブアプリ専用。Webからは OS共有シート経由(公式ドキュメントなし)。推奨 9:16 / 9:18、最小720×1280
- **TikTok**: Webからの投稿はContent Posting API(審査前は非公開投稿のみ、宣伝目的の透かし禁止)。現実的には画面録画をユーザーが自分で上げる経路(統計なし)
- **LINE**: シェアボタン/URLスキームはURLとテキストのみ、画像不可。`?openExternalBrowser=1` で外部ブラウザへ
- **Web Share API**: Android Chrome 76+/iOS Safari 14〜15+ でファイル共有可。**Android WebView 非対応** → 各SNSのアプリ内ブラウザ(Android)では共有シートを呼べない可能性。HTTPS+ユーザー操作起点が必須。iOSでは files と url を同時に渡すと画像が落ちる報告あり(個人ブログ)

## 5. 追加調査: 元ネタの怪談と類似作(2026-09-30)

### 「エレベーターで異世界に行く方法」
- 【事実】最古の確認例は2ちゃんねる 2008-11-22 の投稿(Lucia Peters の調査を creepypasta.com が紹介)。ルールは複数投稿者が後から付け足した。韓国発祥説も多いが年代調査では日本が先。https://www.creepypasta.com/the-elevator-game/ / https://www.gizmodo.jp/2009/04/post_5354.html
- 【事実】代表的手順: 4→2→6→2→10、10階で5を押すと女が乗る(話しかけてはいけない)、1を押すと上昇し異世界へ。(webムー 2025-01-30) https://web-mu.jp/history/51516/
- 【事実】英語名 "The Elevator Game"。2023年に米映画『Elevator Game』。
- 【事実】実在の死亡事件(Elisa Lam さん 2013、港区シティハイツ竹芝 2006)と結びつけて語られることがある。→ 扱いに注意。
- 【事実】確認した資料で原作者名は挙がっていない。
