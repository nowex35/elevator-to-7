# 7階行きのエレベーター シナリオ骨組み(草案 v1.1 / 2026-09-30)

> 状態: **草案**。【Claude案】【Claude仮決定】はユーザー未承認の提案。

## 0. 決まっていること(ユーザー決定)

- 縦画面 2D・写真風・Web(日英対応)。公開SNSでの拡散が目的。
- 8番出口型:驚き(実況の切り抜き)と考察の両方を狙う。
- 舞台はエレベーター。「乗ってくる人」が軸。
- シナリオは **A(貼り紙のルール)× B(住人を覚える)**、外枠は **C(帰宅)**。
- 怪異は掛け算:一つひとつは全員共通、組み合わせは人ごとに違う。
- 1プレイは基本5分以内。うまく進めば長くなる。
- 怖い人(お坊さん等)を入れる。
- **短く遊んで拡散してもらう**。長いプレイにはしない(延長戦なし)。
- **上って7階へ帰る**。今夜6階で通夜がある。「誰の通夜か(あなた自身)」のひねりは入れるが、確定させず余白にする。
- **異変のある人を乗せたら即ゲームオーバー(ドボン)**。
- 説明されない異変(どのルールにも書かれていない異変)は **1回のプレイに1つ**。

## 1. 外枠(C:帰宅)

深夜、古い団地に帰ってきた「あなた」。部屋は **7階**。1階でエレベーターに乗り、7を押す。
押したのは7だけなのに、エレベーターは途中の階で止まり、扉が開く。

### 進行のしくみ

- 1階で乗り、7を押す。エレベーターは **2→3→4→5→6階と順番にすべて止まる**。扉が開くたびに判断する(各階に「いつもの住人」が決まっているので、挑み直すうちに覚えられる)。
  - エレベーターが止まっても、扉は勝手に開かない。**毎回、自分で「開」を押して開ける**。開いている間に「開」を押すと開けたままにできる(実物と同じ)。
  - **ほとんどの階は誰もいない**(深夜なので)。住人がいるのは約3割、6階は通夜なので約6割。
  - **異変なし** → 何もしない。扉は約6秒で自然に閉まる(乗ってくる住人はそのまま乗る)。表示が1つ上がる。
  - **異変あり** → 「閉」を押す。表示が1つ上がる。
- **2〜6階の5回を続けて正しく判断すれば、7階に到着してクリア。** 7階は判断ではなく到着の場面で、通夜のひねりのヒント(D4)を見せる。
- **ミスは即ゲームオーバー(ドボン)**:
  - 異変のある人を乗せた → 扉が閉まり、扉の映り込みで「すぐ後ろに立っている」のが見えて終わる(実況の切り抜きになる見せ場)。
  - 廊下の異変を見逃した → ゲームオーバー。
  - **異変がないのに閉めた → ドボンにしない。待っていれば入った点の半分を引く**(ユーザー決定。2026-09-30 に「点が入らないだけ」から変更)。その場では「ビビッ」と鳴って階数表示が乱れ、スマホなら短く2回震える(何を間違えたかは言わない)。
- 1回のプレイは長くても約1分半(5停止×約12秒+演出)。**何度も挑み直す中で住人の「いつも」を覚える**。

## 2. 今夜の設定(決定)

**今夜、この団地の6階で通夜がある。** ユーザーの「お坊さんを入れたい」を物語に組み込むための提案。

- お坊さん・喪服の女・葬儀社の男が乗ってくるのは、**今夜に限っては「普通」**。
- 通夜の主(亡くなった人)は6階の老人。寝間着・裸足の老人は **どの階から乗ってきても必ず異変**。
- 誰の通夜なのかのひねり:「6階の老人」ではなく「7階=あなた」の通夜かもしれない、と匂わせる。確定はさせず、考察の余白として残す。
- **7階の結末は、その夜に見たものによって変わる**(ユーザー決定。毎回同じ結末だとオチが薄まり、シェアのカードでネタバレになるため):
  - その夜に、自分の部屋(707)を指す異変を**開けて見届けていた**ら、7階で通夜の列(葬儀社の男・喪服の女・お坊さん)が「おかえりなさい」と迎える。記録の最後は「7F おかえりなさい」。
  - 対象の異変:707号室宛の荷物/7階まで行くお坊さん/早すぎる「おかえりなさい」。「707の方ですよね」は出やすく(対象にすると約31%の夜が該当した)、結末が珍しくなくなるので対象から外した(ユーザー決定)。
  - それ以外(対象の異変がない夜・その階を通過した夜)は、誰もいない7階の廊下で終わる。記録の最後は「7F 誰もいなかった」。
  - 対象の異変がある夜は約31%(うち「707の方ですよね」だけの夜が26.5%)。

## 4. 貼り紙(A:ルール)

かごの中に貼られた、管理組合からの「夜間のエレベーターご利用について」。

- **貼り紙は乗る前(最初の画面)にしか読めない**(ユーザー決定)。世界観上は「かごの奥の壁にあり、乗ったら振り向いてはいけない」。途中で見ようとすると「……振り向かないほうがいい。」とだけ出る。文字は HTML なので日英を切り替えられる。
- **掛け算**:ルールの候補(約12個)から、毎回5〜7個が選ばれる。**人によって貼り紙の中身が違う**ことが「自分だけの体験」になる。
- 公平さの方針(決定):1回のプレイにつき **1つだけ**、どのルールにも書かれていない異変がある(=説明されない異変。考察の燃料)。それ以外の異変は、その回の貼り紙のどれかのルールでカバーされている。
- 説明されない異変も、1行ルール「おかしければ閉める」で正解できるので不公平にはならない。
- **貼り紙の最後に、毎晩必ず「上記のほか、少しでも異常を感じた場合は、扉をお閉めください。」を番号つきで載せる**(ユーザー決定)。貼り紙に書いていない異変もドボン対象であることを、作中の文言で伝えるため。
- 雰囲気づくりのルール(扉に映る自分に話しかけない/4階のボタンを押さない/お坊様が降りる階で頭を下げる)は、操作に関係しない。世界観づくりのため残す(ユーザー決定)。

## 5.5 掛け算の構造(指数的な組み合わせ)

階ごとに独立して変わる軸を重ね、5階分でべき乗になるようにする。

| 軸 | 種類 | 性質 |
|---|---|---|
| 住人 | 無人(約7割)/その階の住人(2〜3人) | 普通 |
| 照明 | 全点灯/1本ちらつく/奥が消えている/奥の暗がりが手前の人の顔にもかかる | 普通(ちらつきは貼り紙の但し書きで「点検中」と明示)。「手前の人の顔にもかかる」は、**わざと紛らわしくした異変ではない照明**(ユーザー決定)。開けた時から暗く、途中で変わらないので、R12「明かりが奥から消えていく」とは区別できる。迷って閉めても失敗にはならない(その階の点が入らないだけ) |
| 置き物 | 三輪車・段ボール箱・ビニール傘の有無(三輪車と傘は同じ階に出さない) | 普通。**同じ物が2階続けて出ることはない** |
| 物音 | 静か/雨/遠くのテレビ/6階は読経 | 普通。**音だけの異変は作らない**(消音で遊ぶ人がいるため) |
| 異変の配置 | 5階中2〜3階。うち1つは説明されない異変 | — |
| 貼り紙 | ルール候補10個から、必要なもの+埋め草で5〜6個 | — |

- 揺らぎと組み合わさって初めて生まれる異変:
  - **ついてくる物**(R11):前の階と同じ置き物がある(普通の揺らぎでは同じ物が続かないので、続いたら異変)
  - **明かりが消えていく**(R12):扉を開けたあと、廊下の照明が奥から手前へ消えていく
- 説明されない異変の候補:扉の隙間の指/扉が開いている間だけ階数表示が「13」/住人が「707の方ですよね」と言う/5階のお坊さんが「7階まで、ご一緒します」と言う/配達員の箱の宛名が707号室
- 夜の番号は約43億通り(32bit)。作中では「記録番号 0123-4567-89」として見せる。
- 検証(モック時点):20000夜を作って全部違う組み合わせ。1階あたり実測で約940〜1200通り、5階分で約1.4×10¹⁵通り以上。50000夜で「重なり・ついてくる物の元がない・普通の階で同じ物が続く・貼り紙に対応ルールがない・説明されない異変が1つでない」がすべて0件。

## 5.6 通過とスコア(ユーザー決定)

- 止まった階では、**開けて確かめる**か、**閉で通過する**かを選ぶ。
  - 通過:安全。スコアは入らない。
  - 開ける:「閉める/待つ」を判断する。**正しく判断すると、出会った現象ごとにスコアが入る**。異変を見逃すとドボン。異変がないのに閉めた階は、待っていれば入った点の半分を引く(ドボンにはならない。合計は0点で止める)。結果画面の「出会った現象」に「閉めなくてよかった扉 −○○」と出る。
  - **何もなくてちゃんと待った階には定常点が入る**(誰もいない階=「静かな階」600、住人のいる階 640〜780)(ユーザー決定)。
  - 抜け道対策の確認(模擬):「毎回開けて毎回閉める」は死なないが、減点があるので正しく遊んだ人の約4割の点にしかならない(2026-09-30、2万夜・反応2.5秒・ためらい1.5秒で固定して比べると 約5,500 対 約13,200)。減点を入れる前は約半分だった。
- **ドボンしたらスコアは0**(7階に帰り着いて初めて確定する)。
- 単位は**単純な数字**(ユーザー決定。お金の単位は使わない)。珍しさは★で表す。ドボン時は「記録が途中で途切れたため、スコアは記録されません。」
- **プレー中はスコアを一切出さない。結果画面でだけ出す**(ユーザー決定。冷めるため)。
- **スコアは細かく刻み、人によって差が出るようにする**(ユーザー決定)。1つの現象の点:

  `基本点(★) × 階の高さ × 連続で開けた数 × 開けるまでのためらい × 反応の速さ × 暗さ`

  | 要素 | 中身 |
  |---|---|
  | 基本点 | 現象の珍しさ(★)ごと。きりのいい数からずらす(例:★1つは640〜780) |
  | 階の高さ | 2階 1.00倍 〜 6階 1.60倍 |
  | 連続で開けた数 | 通過せずに開け続けた数。1つ増えるごとに +0.25倍 |
  | 開けるまでのためらい | 着いてから「開」を押すまでが速いほど高い(最大1.5倍) |
  | 反応の速さ | 異変のみ。扉が開いてから「閉」を押すまでが速いほど高い(最大約2倍) |
  | 暗さ | 奥が暗い・手前の人の顔にもかかる 1.2倍/ちらつく 1.1倍 |

- 点の桁(ユーザー指摘で100倍をやめた):真ん中の人で約6,500点、上位1%で約2万点。1万人の中では同点が出やすいが、友達10人で比べて同点が出るのは約1%(同じ人を2回数える分を含む)。
- スコアと★(★は実際に出る割合で決める。2026-09-30 に管理人を減らした後、10万夜で測り直した):
  - 境目【Claude仮定】:★5 は 0.45% 未満/★4 は 2.9% 未満/★3 は 5% 未満/それ以上は★2(普通の住人は★1)。もとの表の範囲どうしのすき間の真ん中を境目にした。

| ★ | 現象 | 基本点 | 出る夜の割合 |
|---|---|---|---|
| ★ | 住人に会った(普通。おじさんを含む。配達員とお坊さんを除く) | 640〜780 | 4.9〜31% |
| ★★ | お坊さん(普通)/よく出る異変(靴、老人、違う階、喪服、明かり、指、13階、707、ついてくる物、会釈しない管理人、近づいてくる人、開いたドア、違う廊下、進まない表示、4を押す住人) | 450〜1,040 | 5.0〜23% |
| ★★★ | 配達員(普通)/行き先を押さない子/裸足の住人 | 1,540〜1,880 | 3.4〜3.7% |

## 5.9 サーバー(Cloudflare Workers + D1)【Claude仮定:技術選定】

- 遊び終わったら結果を保存し、7階に帰り着いたときだけ、**結果画面に**全体の順位を出す:「あなたのスコアは ◯人中◯位」(100人以上になったら「上位◯%」)。この夜・今日の人数などは出さない(ユーザー決定)。
- 「◯◯に気づけた人 ◯%」は出さない(ユーザー決定)。開けて判断した記録は、難易度調整の材料として `runs.enc`(JSON)に保存だけする。
- **無料枠に収める**(ユーザー決定。Cloudflare の無料プランのまま):
  - Worker が処理するのは `/api/*` だけ。ゲーム・シェア用ページ・カード画像は静的ファイル(無料・回数無制限)。
  - 1回のプレイで書く行はドボン1行/帰り着いた3行(記録・索引・度数表)。書き込みの上限(10万行/日)まで、帰り着いたプレイで約3.3万回/日。
  - 順位は、帰り着いた人が2,000人未満のうちは正確に数える。それ以上は500点ごとの度数表から出す(3,000人の模擬で、正確な順位との差は最大9位、「上位◯%」は一致)。
- **シェア用のページ** `/s/<言語>-<結果>`(結果 = 7 か、途切れた階 2〜6):SNS のカード情報を返し、開いた人は**新しい夜**を遊ぶ(ユーザー決定。同じ夜は渡さない)。
- **結果ごとのカード画像** `/og/<言語>-<結果>.png`(1200x630、日英×6種の12枚+トップページ用1枚):左に記録紙(夜間運行記録・結果・2F〜7Fのどこまで行けたか・誘い文)、右に写真。`scripts/build-cards.mjs` がビルド時に作る。
  - スコアはカードに載せず、シェア文にだけ出す(ユーザー決定。サーバーでカードを作ると、無料プランの処理時間の上限を超えるため)。
  - 写真:クリア時は「誰もいない7階の廊下」(通夜の結末を見せない)、ドボン時は「閉じた扉に老人がうっすら映る」。
- **共有先**:Xでシェア/LINEで送る/画像で共有/コピー。「画像で共有」はブラウザで縦長(1080x1920)の画像を描き、スマホの共有メニューに渡す(ストーリーズ向け)。共有メニューが使えないとき(PC・一部のアプリ内ブラウザ)は、画像を出して保存してもらう。

- 【Claude仮定】サラリーマンの行き先を4階から5階に変えた。普段から4が点くと「4を押す住人」に気づけないため。

- 検証(10万夜):説明されない異変がちょうど1つでない夜/ルールのある異変なのに貼り紙にそのルールがない夜/ついてくる物の元がない/2階の「進まない表示」/同じ背景への入れ替え/普段の住人が4を押す、がすべて0件。

## 5.11 7階に近づく焦り(2026-09-30。ユーザー決定)

- 階が上がるほど、鼓動が速く強くなる:3階 62/分 → 4階 74 → 5階 88 → 6階 104 → 7階へ向かう間 124。2階では鳴らさない。
- 鼓動に合わせて、視界の縁の赤いもやが脈打ち、景色(廊下と扉)が揺れる。表示とボタンは揺らさない(押しにくくなるため)。
- 6階から先は、ごく小さな耳鳴り(じんじん)を重ねる。
- 7階で扉が開くと止む。ドボンの一撃の前と結果画面でも止める。
- 【Claude仮定】端末で「視差効果を減らす」を選んでいる人には、揺れだけ出さない(赤いもやと音は出す)。

## 6. ゲームオーバー(ドボン)

- 異変のある人を乗せる → 扉が閉まる → 扉の映り込みで、その人が **あなたのすぐ後ろ** に立っているのが見える → 一歩近づく → **一撃** → 暗転 → 結果画面。
- 廊下の異変を見逃した → 扉が閉まる → (人が違和感なら)閉じた扉にその人がうっすら映る → **一撃** → 暗転 → 結果画面。(異変がないのに閉めた場合はドボンにしない)
- **一撃**(ユーザー決定:ドボンは怖い演出で終わる):環境音が消えた「間」のあと、顔が画面いっぱいに迫り(約0.4秒、揺れと残像)、鋭い音とともに一瞬で黒になる。Android はスマホが震える。
  - 時間:扉が閉まってから、乗せた場合 1.6秒/見逃した場合 1.7秒で一撃 → 0.4秒 → 黒 1秒 → 結果画面。
  - **顔は違和感ごとに違う**(ユーザー決定)。白黒・高コントラスト・暗く加工する。
    - 人そのものが違和感(裸足の老人・会釈しない管理人・6階ではない喪服・「707の方ですよね」・いつもと違う階の住人・また乗ってくる人・7階まで行くお坊さん・707号室宛の荷物・背を向けた管理人):**その人の顔**(元の写真から切り出し)。早すぎる「おかえりなさい」は葬儀社の男。
    - 物や現象の違和感(そこにいた人は無関係なので出さない。生成画像 `assets-src/faces/`):隙間の指=**ドアの隙間からのぞく片目**/赤い靴=**上がり込んだ黒髪の女**/13階=**名簿にいない青白い男**/消えていく明かり=**闇から浮かぶ顔**/ついてくる物=**顔の見えない人影**(三輪車から子どもを連想させないため)/全部点いたボタン=**耳元の横顔**。
    - **男の子の違和感は、男の子の顔を出さず「男の子の後ろにいた女」の顔にする**(ガードレール「子どもを死者として扱わない」)。
  - 血・傷・顔の歪みは足さない(ガードレール「過度な流血・遺体の直接描写はしない」)。明るさ・コントラスト・揺れ・残像だけで作る。
  - 明滅は「顔が出る→黒」の1回だけ(1秒に3回を超える点滅は、光に敏感な人の発作の原因になりうるため避ける。若年層向けの公開が前提)。
- **結果画面で「何が起きていたか」を1行で明かす**(ユーザー決定)。例:「管理人は、いつも3階から乗る。」「この階には、何もおかしなことはなかった。」 初めての人は住人の「いつもの階」を知らないので、明かさないと次に活かせず不公平になるため。当初の「明かさない(考察の余白)」方針は撤回。
